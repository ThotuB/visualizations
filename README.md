# Visualizations

Sketches that show how an algorithm or a piece of math works. Experiments where the output itself is the point live in `generative-art`.

## Running

- **p5.js**: open the sketch's `index.html` in a browser.
- **Processing**: open `Main/Main.pde` in Processing.

## Sketches

### sorting

| Sketch | Tool | What it shows |
|---|---|---|
| `all-sorts` | p5.js | 10 sorting algorithms (bubble ×3, cocktail shaker, insertion, quick, radix ×2, selection, shell) on random or sorted input |
| `crazy-shell-sort` | p5.js | Shell sort, as a full run (`algorithm`) and step by step (`step-by-step`) |
